1. Firmware and scope

TL-MR3020 EU Ver. 3.30 only, original bootloader; USB Type-C power. Stock target: 1.8.0 0.9.1 v0001.0 Build250625 Rel.56805n. The source ZIP name says 1.7.0; its BIN says 1.8.0. Other revisions are not supported.

2. Offline preparation

The repository contains the original OEM ZIP, embedded Python, preparation scripts and vendor snapshots. Run tools/setup/Prepare-Recovery.ps1 on Windows 11 x64, extract the resulting ZIP to a local disk and run Recovery.cmd -DryRun. Preparation needs no downloads, WSL or installed Python.

3. Local checks

DryRun checks files and local network prerequisites without contacting a router or changing settings. Do not press Reset. CheckOnly separately checks files and loopback TFTP. Neither proves hardware compatibility or boot success.

4. Recovery and password

Back up required data first. Use dedicated Ethernet with DHCP. Run Recovery.cmd as Administrator, confirm the model and RESTORE FACTORY. Only after READY hold Reset at power-on; release when transfer starts and keep power connected. A transfer ACK does not prove boot. The old TP-Link password may remain; a separate reset on the powered-on, booted router clears settings and lets you set a new password. The wizard never resets settings automatically.

5. Result and archived sources

On 2026-11-09 the prepared image restored OpenWrt to OEM; the owner verified the stock UI/version after a separate reset. The original up_boot BIN has a 512-byte offset incompatible with the observed recovery copy layout. The pinned transformation is 128 KiB of zero prefix plus the unchanged original bytes from 0x20200. The complete new wizard and OEM-to-OEM remain untested on hardware.
