Перенос календарных планов · .sbpПодробности ▾

Создайте планы в календаре, затем выберите их для экспорта. В файл войдут связанные расписания, цвета и предзвонок. Pages поддерживает только штатные мелодии. Файлы обрабатываются в браузере, без отправки на сервер.

На этом этапе импорт только проверяется: существующие планы не изменяются. Для добавления используйте «Календарь → Импорт календарного плана .sbp» на совместимом устройстве. Здесь доступен только предварительный просмотр без записи.

Планы для экспорта

Экспортируется текущий черновик, включая несохранённые правки. Сначала примените введённые название и даты плана. Экспорт не сохраняет и не включает план.

Выберите планы и часовой пояс для экспорта либо файл для проверки.
