# Pages «Школьника»

[English](README.en.md) · [Карта документов](../docs/README.md)

`make check-site` собирает `out/site` и проверяет маршруты, общие ассеты,
метаданные сборки, перенос localStorage и экспорт/предварительный импорт `.sbp`.
Корень `/schoolbell/` — интерфейс звонка, без отдельной обложки проекта.
`guide.html` и `training.html` (также `.en.html`) и `devices/` — отдельные страницы.
`ranges.html` возвращает в общий календарный редактор. Установленный UI берётся
из `ui/root`; Pages добавляет имитатор API, не обращающийся к оборудованию.
Шесть штатных MP3 доступны в браузере. Пользовательские медиа и команды
реального устройства не предоставляются. Формы Issues ведут в schoolbell.

## Черновики

Новый ключ — `schoolbell-public-demo-v1`. Старый
`openwrt-schoolbell-public-demo-v1` не меняется и не удаляется. Если нового ключа
нет и прежний черновик проходит проверку, в подробностях плашки демо доступна
кнопка «Перенести прежний черновик». Копирование требует подтверждения,
сохраняет данные и выключает только имитацию автозвонков. При наличии новых
сохранённых данных или несохранённых правок перенос не перезаписывает их.
Сброс демо меняет только новый ключ. При запрете хранилища старые данные не
трогаются; используйте экспорт `.sbp` на прежней странице. Это работает между
путями одного origin; другой домен требует ручного переноса `.sbp`.

## Публикация владельцем

После принятия ветки и успешного CI в GitHub Settings → Pages выбрать
GitHub Actions. Запустить workflow **GitHub Pages** вручную с `main`.
Обычный push сайт не публикует. SHA и дата сборки видны в «Обратной связи»
и `build-info.json`; локальная сборка с изменениями помечена явно.

Руководство/устройства сохраняют исторические сведения исходного стенда и
помечены черновиком переноса. Это не новая аппаратная приёмка. Прошивки,
бэкапы и закрытые данные в статический сайт не включаются. В эту итерацию
публикация, переходы со старых Pages и устройства не входили.
