# Школьник

[![CI](https://img.shields.io/github/actions/workflow/status/ViacheslavMezentsev/schoolbell/ci.yml?branch=main&label=CI&style=flat-square)](https://github.com/ViacheslavMezentsev/schoolbell/actions/workflows/ci.yml)

[English](README.en.md)

**Школьник — настраиваемый музыкальный звонок для OpenWrt с управлением из браузера.**
Расписания и календарные планы исполняются на устройстве без открытой страницы.

## Возможности

- Календарные планы с диапазонами дат, раскраской дней и предпросмотром.
- Штатные и пользовательские MP3, предзвонок, ручной звонок и отключение звука.
- Контроль времени, журнал событий, резервные копии `.sbb` и перенос планов `.sbp`.

## Сборка и проверка

После подготовки [зависимостей хоста](docs/BUILD.md):

```sh
make all
```

Собирает IPK и запускает host-тесты без обращения к устройству.
[Автономный комплект зависимостей](docs/PACKAGING.md) готовится отдельно.

## Состояние

проверка опубликованных Pages и новая аппаратная приёмка ещё впереди. [План миграции](docs/MIGRATION.md).

## Лицензия

Собственный код и документация — [MIT](LICENSE). Аудио, исторический архив и
сторонние компоненты исключены; см. [область действия](docs/LICENSING.md) и [NOTICE](NOTICE).

Под Flash показаны контроллер и имя карты выхода по умолчанию `/dev/dsp`, справа — сохранённая громкость в % (дБ). При отсутствии выхода отображается «не обнаружено»; другие карты автоматически не выбираются. Проценты — коэффициент усиления, не измеренная слышимость. Flash показывает МиБ (1024² байт); нормальный уровень до 75% синий.
