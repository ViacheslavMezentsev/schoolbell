# Школьник

[English](README.en.md) · [Начать установку](docs/GETTING_STARTED.md) · [Руководство пользователя](docs/user/USER_GUIDE.md)

**Школьник — музыкальный школьный звонок на небольшом роутере.** Он воспроизводит мелодии по расписанию и календарному плану. Настройки открываются в браузере компьютера или телефона; во время работы звонков держать браузер открытым не нужно.

Можно задать обычные и праздничные дни, предзвонок, свои мелодии, подать звонок вручную или временно отключить звук. После настройки звонки работают и без Интернета; перед включением нужно проверить часы устройства.

## Что входит в проект

- **Школьник** — расписания, календарь, мелодии и журнал звонков с управлением в браузере.
- **Мастер установки для Windows** — установка OpenWrt на роутер, установка комплекта Школьника и возврат заводской прошивки.
- **Комплект установки** — отдельный ZIP со Школьником, необходимыми пакетами и инструкциями.
- **Демонстрация и руководства** — знакомство с интерфейсом и помощь при сборке системы.

## Что понадобится

| Оборудование | Рекомендация |
| --- | --- |
| Роутер и питание | Проверенный профиль мастера: **TP-Link TL-MR3020 (EU) Ver. 3.30**. У этой ревизии питание USB Type-C; точную ревизию проверяйте на наклейке. |
| USB-аудиокарта | Проверялись карты, определяемые как **AB13X USB Audio** и **C-Media USB PnP Sound Device**. |
| USB-хаб, если нужен | Пока используйте подключение, при котором аудиокарта показана как **OHCI** в «Метрики → Ресурсы». На проверенном сочетании хаба с EHCI были пропуски запуска звука. |
| Колонки | Активные колонки или усилитель с колонками и кабель к аудиокарте. |
| Для установки | Компьютер с Windows 11 x64, отдельный **USB–Ethernet-адаптер**, сетевой кабель и питание роутера. |

OHCI — обозначение контроллера подключения, а не марка хаба. Одна такая надпись не гарантирует работу любого оборудования: перед использованием проверьте слышимость звонков по расписанию. [Проверенные подключения и ограничения](docs/HARDWARE.md).

## С чего начать

1. Подготовьте оборудование по списку выше.
2. Откройте [инструкцию по файлам релиза](docs/GETTING_STARTED.md): она объясняет, что скачать и как пройти нужный сценарий мастера.
3. Настройте календарь, расписание и звук по [руководству пользователя](docs/user/USER_GUIDE.md).
