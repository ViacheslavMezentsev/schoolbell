# Мастер установки — предварительный выпуск

[English](README.en.md)

Для Windows 11 x64 и TP-Link TL-MR3020 **EU Ver. 3.30** с оригинальным загрузчиком.
Другие ревизии не проверены. Нужны питание роутера, отдельный USB–Ethernet,
кабель RJ45, установленный PowerShell 7 и компонент Windows OpenSSH Client.
Для установки пакетов нужен пароль root OpenWrt; задайте его через LuCI.
Python поставляется внутри, устанавливать Qt/MSYS2/Python не нужно.

1. Распакуйте весь ZIP в отдельную папку. Не запускайте EXE из просмотра ZIP.
2. Запустите `schoolbell-setup-wizard.exe`. Выберите нужную операцию и выделенный адаптер.
3. Для OpenWrt или заводской прошивки оба образа уже встроены. Разрешите UAC.
   Нажимайте Reset и подавайте питание только после READY по подсказкам мастера.
   После передачи оставьте питание включённым до загрузки; дождитесь восстановления сети.
4. Для Школьника скачайте отдельный `schoolbell-v…-openwrt-19.07.9-ramips-mt76x8-mipsel_24kc.zip`.
   Положите рядом с EXE или выберите в форме. ZIP не распаковывайте.
   Введите пароль, проверьте устройство, затем отдельно подтвердите установку.
5. Откройте интерфейс роутера и проверьте версию. Новая установка оставляет автозвонки выключенными.

Возврат OEM использует Build250625, а не произвольную исходную OEM-версию.
Прежний пароль TP-Link может сохраниться; сброс настроек — отдельное действие,
не часть перепрошивки. Полная копия в мастере доступна из OpenWrt и необязательна
для прошивки; из OEM настройки сохраняются через TP-Link Backup & Restore.

## Известные ограничения

Это preview без Authenticode. После перепрошивки OpenWrt сохранённый SSH-ключ
может не совпасть: GUI пока не выполняет его замену. Не отключайте проверку ключей;
нужна сверка нового ключа и адресная замена старой записи специалистом.
Ошибка подготовки до записи может потребовать нового сеанса.
Полный цикл проверен с таким ручным исправлением, а не безусловно на чистом ПК.
Чистая Windows без среды разработки и этот точный ZIP ещё требуют отдельной проверки.
Лицензионные материалы неполны, статус перечислен в licenses/OPEN-ITEMS.md.
SHA256SUMS проверяет целостность, но без доверенной подписи не удостоверяет издателя.
