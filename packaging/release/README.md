# Комплект Школьника — кандидат

[English](README.en.md)

**Локальный кандидат, не публичный установочный релиз.** В комплект входят Школьник,
нативный модуль часов и 33 закреплённые зависимости. GUI и прошивка поставляются отдельно.

## Совместимость и границы

OpenWrt 19.07.9, ramips/mt76x8, mipsel_24kc, TL-MR3020 v3; точные kernel/libc проверяются.
Опыты проекта с EU v3.30 не означают аппаратную приёмку этого ZIP. Ручной установщик
поддерживает **чистую OpenWrt**. Обновление старого Школьника, repair, перепрошивка и
автоматический откат пока не поддерживаются. Уже установленная версия не переустанавливается.

Скрипты запускаются на компьютере с Python 3.8+ и OpenSSH. Python на роутер не нужен.
Windows: `python` или `py -3`; WSL/Linux: `python3`. GUI 0.1.0 пока использует прежний
встроенный комплект; выбор этого ZIP в GUI — отдельный следующий этап.

## До подключения

Распакуйте ZIP в отдельный каталог на ПК, проверьте источник и SHA256SUMS архива.
Хеши обнаруживают повреждение, но не удостоверяют автора; подписанные загрузки пока
не реализованы. Не переносите полный ZIP в RAM роутера. Не меняйте kernel/libc,
не обновляйте feeds и не устанавливайте все IPK через wildcard.

Нужны отдельное Ethernet-подключение, питание, известный пароль root либо SSH-ключ,
заранее сверенный ключ устройства в known_hosts и проверенный образ восстановления
той же OpenWrt. Скрипт не принимает неизвестные SSH-ключи автоматически и не меняет
маршруты. Укажите IPv4 именно нужного устройства и локальный IPv4 выделенного адаптера.
До работы автозвонки должны быть выключены. Кнопка Reset при установке пакетов не нужна.

Образ `tp_recovery.bin` не входит в этот ZIP. Подготовьте его по руководству tools/setup;
установщик принимает только SHA256
`e621da95d07d25102b1016a28400122f5c92bce9830d5cc061323e306b6204fa`.
Сеанс храните вне распакованного комплекта, в личном каталоге: копия overlay содержит
пароли и настройки. Не публикуйте её и не помещайте в Git.

## Подготовка, установка, проверка

Команды выполняются из распакованного комплекта на ПК. Замените ROUTER_IP, PC_IP и
KNOWN_HOSTS своими значениями; укажите пути к исходному ZIP и образу восстановления.
Каталог сеанса должен быть новым; существующая копия никогда не перезаписывается.

```sh
python3 scripts/install.py prepare --zip ../schoolbell-v5.1.127-openwrt-19.07.9-ramips-mt76x8-mipsel_24kc.zip --recovery ../tp_recovery.bin --session ../install-session --host ROUTER_IP --source PC_IP --known-hosts KNOWN_HOSTS
python3 scripts/install.py install --session ../install-session
python3 scripts/install.py verify --session ../install-session
```

`prepare` проверяет ZIP, профиль, инвентарь и место. Сохраняет полный overlay, список
пакетов, идентичность устройства/загрузки, хеши защищённых настроек и образ восстановления
на ПК. Проверяет хеш передачи и читаемость архива. `PREPARED` появляется только после
успешной копии. Резерв RAM под создание копии учитывается отдельно от IPK.

`install` требует ввести `INSTALL ROUTER_IP`. Подготовка действует 30 минут. Проверяются
сеанс, хеши IPK и копии, подключение, прежняя загрузка, инвентарь, настройки и свободное
место. Передаются только недостающие пакеты; проверяются SHA256 и явный список opkg.
Успех означает проверенные версии, работающие службы, выключенный автомат и сохранённые
сетевые/системные настройки. На чистой системе нет прежних планов и настроек Школьника.

При обрыве или неизвестном результате сохраняется `write-started`. **Не повторяйте
install, не удаляйте маркер и не начинайте новую установку обходом этого ограничения.**
Используйте `verify` с прежним сеансом. Неудачная проверка удаляет старую отметку успеха.
После смены загрузки/ключа либо частичной установки нужна отдельная диагностика;
установщик не пытается автоматически дописать или откатить пакеты.

Сеанс содержит `bundle.zip`, проверенный `overlay.tar`, `backup.tar`,
`openwrt-recovery.bin` и связанные квитанции. План восстановления: та же OpenWrt через
Reset и восстановление сохранённого overlay по отдельной процедуре, не команда install.
Полный аппаратный цикл восстановления этой копии ещё требует приёмки.

Соседний `.guard` и `/tmp/schoolbell-release.lock` предотвращают параллельный запуск
этого установщика. После аварии оставшийся lock требует разбора; не удаляйте его при
работающей операции. Не запускайте параллельно другие средства установки или настройки.

## Проверки без установки

`snapshot.sh` читает состояние устройства; сохраните вывод вне комплекта в UTF-8.
Ошибочный или неполный вывод использовать нельзя. На ПК:

```sh
python3 scripts/plan.py --snapshot ../snapshot.tsv
```

План помечен `preliminary-only` / `write_authorized=false`. Снимок может устареть;
он не заменяет живые проверки, копию и подтверждение. `check.sh` и `verify.sh` — прежние
проверки полного распакованного каталога на подходящем хранилище устройства, не установщики.

## Статус

Транзакция проверяется локально на искусственных данных и подменённом SSH, включая
исполнение shell-проверок в изолированной файловой системе. Аппаратная приёмка ZIP,
интеграция GUI, Windows SSH-транзакция, соответствующие исходники зависимостей и права
аудио остаются открыты. `distribution_cleared=false` и `hardware_validated=false`
сохраняются. packages/ содержит исходные IPK, licenses/ — лицензии и открытые вопросы,
RELEASE_NOTES.md — заметки, manifest.json/input-manifest.json — происхождение.
