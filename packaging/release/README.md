# Комплект пакетов Школьника — кандидат

[English](README.en.md)

**Это локальный кандидат формата архива, не публичный установочный релиз.**
Версия приложения и список файлов указаны в manifest.json. ZIP включает приложение,
нативный модуль часов и все 33 закреплённые зависимости. Прошивок и самого мастера здесь нет.

## Совместимость

OpenWrt 19.07.9, ramips/mt76x8, mipsel_24kc, MR3020 v3. Точный ABI kernel и libc
проверяет scripts/check.sh. Аппаратные опыты проекта проводились на EU v3.30;
это не подтверждение всех подревизий и не приёмка свежей установки этого ZIP.
Не заменяйте kernel/libc, не используйте --force-depends или --force-overwrite.

## Проверка на компьютере

Распакуйте ZIP в отдельный каталог и проверьте SHA256SUMS. Контрольные суммы
обнаруживают повреждение; подписанного подтверждения происхождения пока нет.
Сначала сверяйте источник загрузки. Не переносите весь архив в /tmp малопамятного
роутера без проверки свободной RAM. Распаковка выполняется на компьютере.

## Для профессионального пользователя

Перед ручной установкой сохраните вне роутера конфигурацию, overlay и план отката;
остановите автозвонки. Сравните `opkg list-installed` с packages.tsv и проверьте
свободные RAM и flash. Уже установленные совместимые зависимости повторно не нужны.
Не устанавливайте весь каталог командой `opkg install *.ipk` и не выполняйте opkg update
ради этого офлайн-комплекта. Передавать следует только необходимые пакеты.

Если весь распакованный комплект размещён на подходящем носителе роутера,
`sh scripts/check.sh` проверит его целостность и профиль устройства без изменения настроек.
Это не проверка достаточности места и не резервная копия.
После отдельно выполненной установки `sh scripts/verify.sh` сверит версии, службы
и выключенные автозвонки. Скрипты не меняют звук, сеть, часы и пакеты.

**Автоматический install.sh и приёмка ручной установки ещё не завершены.**
Этот кандидат не даёт команды установки/отката для неподтверждённых исходных версий.
Мастер 0.1.0 пока использует прежний встроенный комплект; обнаружение этого ZIP — следующий этап.

## Содержимое и ограничения

packages/ — исходные неизменённые IPK; licenses/ — уведомления и открытые вопросы
распространения; RELEASE_NOTES.md — заметки версии; input-manifest.json — происхождение
входного комплекта; manifest.json — формат 1 и происхождение упаковки.
`distribution_cleared=false` и `hardware_validated=false` сохранены намеренно.
Исходники и лицензии сторонних компонентов, права аудио, свежая установка и подписанные
артефакты должны быть подготовлены до публичного выпуска. Копии устройств в ZIP не входят.

## Предварительный план на компьютере

В ZIP добавлены `scripts/snapshot.sh` и `scripts/plan.py`. Первый читает состояние
устройства, второй работает на компьютере с Python 3.8+ и не имеет сетевых операций.
Для согласованного устройства запустите только snapshot.sh через SSH и сохраните
его стандартный вывод на компьютере в UTF-8 как snapshot.tsv. Ошибка SSH/скрипта
означает неполный снимок: такой файл использовать нельзя. Весь ZIP на роутер
копировать не нужно. Команды ниже выполняются на компьютере из распакованного комплекта:

```sh
python3 scripts/plan.py --snapshot ../snapshot.tsv
```

Храните snapshot.tsv вне каталога комплекта: точная проверка SHA256SUMS отвергает
посторонние файлы. В Windows используйте `python` или `py -3` вместо `python3`.
Результат — JSON со списками `install` и `retain`, оценками RAM/overlay и хешами
входных данных. Включены только новая установка и уже установленная целевая версия.
Старая версия требует проверенного отката и пока отвергается; восстановление
неполной установки тоже не выполняется. Резерв оценки — 512 КиБ overlay и 4096 КиБ
RAM. Оценка не гарантирует успешную запись файловой системы и не включает резервную копию.

`preliminary-only` / `write_authorized=false` — предварительная оценка, не допуск
к записи и не проверка работающих служб. Снимок может устареть или быть подменён.
Перед установкой нужны живые проверки, подтверждённая копия вне устройства,
подготовленный откат и согласие пользователя. Скрипта записи в этом ZIP ещё нет.
Хеши обнаруживают повреждение, но не подтверждают доверенный источник.
