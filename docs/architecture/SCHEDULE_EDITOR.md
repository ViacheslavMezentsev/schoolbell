# Редактор сохранённых расписаний

[English](SCHEDULE_EDITOR.en.md) · [Страница и установка](https://github.com/ViacheslavMezentsev/openwrt-modbus-core/blob/243a7ccad6aeb2499d3efd5d0c4cef9e822d393e/packages/schoolbell/router-page/README.md)

Редактор работает на `/cgi-bin/luci/admin/schoolbell` после обычного входа LuCI.
Создайте расписание, задайте название и строки, нажмите **Сохранить черновик
на роутере**. Обновление страницы читает данные с роутера, а не localStorage.
Переключение расписаний не теряет несохранённые правки; выход со страницы
предупреждает о них. Создание, копирование, удаление расписаний и очистка строк
меняют только браузерный черновик до сохранения.

**Ни сохранение, ни флажок строки не включают автоматические звонки.**
Назначение датам и предпросмотр доступны в [годовом календаре](ANNUAL_CALENDAR.md). Кнопки ручного звука остаются отдельными
действиями; редактор их не вызывает.

## Значения и ограничения

- До 16 расписаний; канонический JSON до 12288 байт.
  Все пределы действуют одновременно, поэтому количество строк не гарантирует
  прохождение лимита размера.
- Имя: 1–96 байт UTF-8 без управляющих символов и непустое после пробелов.
- Строка: уникальный внутри расписания `id`, `time` строго HH:MM,
  `media`, булевы `enabled` и `pre`.
- Предзвонок: общий интервал 1–10 минут. Сейчас единственный доступный media ID
  — `test`. Остальные мелодии/замена подключаются отдельно.
- Данные проходят штатный строгий JSON-декодер и проверку календарной модели.
  Неизвестные поля, дубликаты ключей/ID, неверные типы/время отклоняются сервером.

Пользовательские значения имеют вид:

```json
{
  "pre_minutes": 2,
  "pre_media": "test",
  "schedules": [{
    "id": "weekday",
    "name": "Учебный день",
    "rows": [{
      "id": "lesson1",
      "time": "08:00",
      "media": "test",
      "enabled": true,
      "pre": true
    }]
  }]
}
```

Дополнительных версий в пользовательских значениях нет. Это схема черновика
редактора, не завершённый контракт импорта/backup или активного снимка.

## Сохранение и конфликты

GET `schedules` возвращает `ok, revision, data, active=false`; до первого
сохранения revision равен `empty`. POST `save-schedules` принимает
`token, revision, draft` как form-urlencoded. Тело ограничено 49152 байт
до form decoding, draft — 12288. Все URL наследуют авторизацию LuCI;
изменения требуют POST-токен. Клиент не передаёт путь на диске.

revision — SHA256 канонических значений. Он проверяется внутри исключающей
блокировки. Устаревшая вкладка получает conflict, без перезаписи.
Одинаковое содержимое не пишется повторно. A→B→A имеет тот же хеш;
это сравнение содержимого, не поколение активации.

При конфликте/неизвестном результате правки остаются в браузере, но повторное
сохранение блокируется до загрузки и сравнения. Загрузка поверх правок
требует подтверждения их замены. Не закрывайте вкладку, пока не перенесли нужные
правки: автоматического слияния и экспорта черновика в этом этапе нет.

## Постоянное хранение

`/etc/schoolbell-editor` — приватный каталог 0700.
`current.json` содержит служебные `data/checksum`; `previous.json` — предыдущую
целую копию. Это внутренние checkpoints, не пользовательский settings.json.
Файлы не связаны с production-медиатекой и не активируют общий scheduler.

Под блокировкой: проверка текущей версии, места с запасом max(512 КиБ, 10%),
запись next + fsync, сохранение previous через временный файл + fsync/rename,
rename next→current, fsync каталога, проверочное чтение. Пик дополнительно
резервирует 48 КиБ под две временные записи и выделение/метаданные.
Ошибки ENOSPC/fsync/rename проверяются независимо от предварительной оценки.

Повреждённый current или отсутствие current при наличии previous блокируют
сохранение. Автоматического сброса/применения previous нет: сначала диагностика.
Остаточный next никогда не публикуется при загрузке. После неизвестного результата
нужно прочитать current, а не слепо повторить POST. Прерывание процесса снимает
файловую блокировку средствами ОС.

## Проверки и границы

14 host-групп: схема, конфликты, no-op, повреждение, место, write/sync и HTTP guards.
Native host: повторное чтение новым процессом, восемь crash checkpoints,
конкурентный lock и отказ symlink. На MR3020 те же восемь точек прерывания
проверены в /tmp и отдельном постоянном каталоге; стенды удалены.

Это не испытание отключения питания, reboot, полной RAM-квоты или автономного IPK.
Миграция в production-снимок, разрешение ссылок медиатеки и запуск
по расписанию ещё впереди. Полный паритет с исходным schoolbell остаётся в TODO.

Пользователь подтвердил на установленной странице LuCI: название, время и флажки сохраняются после записи и обновления страницы. Автоматические звонки не включались.

Годовые назначения и предпросмотр добавлены следующим этапом: [годовой календарь](ANNUAL_CALENDAR.md). Существующие правила хранения сохраняются; пользовательские данные могут дополнительно содержать plans.

С 5.1.24 отдельные пределы числа строк сняты. Сохраняются размер черновика 12288 байт и бюджеты расчёта событий; вместимость зависит от данных. Большие планы могут не импортироваться старыми версиями — используйте совместимую версию устройства и Pages.
