# Годовой календарь и предпросмотр

С 5.1.0 рабочий календарь использует именованные диапазоны. Этот документ описывает исходный годовой формат; актуальные UI, совместимость и миграция — [Календарные планы](RANGE_PLANS.md).

[English](ANNUAL_CALENDAR.en.md) · [Редактор](SCHEDULE_EDITOR.md)

На странице schoolbell выберите год и расписание в поле **Назначать дням**.
Нажмите даты или примените диапазон с фильтром всех дней, Пн–Пт либо Сб–Вс.
«Тихий день» снимает назначение; очистка года требует подтверждения.
Годовая сетка начинается с понедельника, выходные подчёркнуты, расписания
обозначены цветами и названиями. На узком экране месяцы располагаются одной колонкой.

**Сохранить черновик** записывает расписания и планы одной версией.
Изменения во второй вкладке вызывают конфликт, а не перезапись.
Без назначения день тихий; без плана на следующий год ничего не повторяется.
Можно хранить до 8 лет, однако общий JSON-лимит 12 КиБ остаётся.
Удаление расписания, назначенного хотя бы одному дню, отклоняется.

Выберите **Дату просмотра** и нажмите **Показать звонки**. Сервер вычисляет
текущий черновик, включая несохранённые изменения, штатным Lua-календарём.
Показываются основные звонки и предзвонки. Предзвонок через полночь отображается
в фактический день вместе с датой основного звонка; в тихий день он подавляется.

**Это местные часы расписания, не UTC.** Предпросмотр не проверяет системный
часовой пояс, переходы часов и готовность к запуску. Он не сохраняет данные,
не регистрирует события и не воспроизводит звук. Автозвонки по-прежнему отключены.

## Формат и совместимость

К прежним значениям добавляется необязательный plans. Каждый элемент:
- year — целое 1–9999, уникальное;
- schedule_ids — до 16 уникальных существующих ID расписаний;
- days — строка 365/366 символов от 1 января: точка означает тихий день,
  A–P ссылаются на позиции 1–16 в schedule_ids.

В браузере формат скрыт за обычным календарём. Полный год помещается компактно
без повторения длинного ID для каждой даты. Сервер проверяет длину, коды,
ссылки, високосность и разворачивает карту для существующего вычислителя.
Неизвестные поля, повторные годы, дробные числа и некорректные ссылки отклоняются.
Это приватный формат неактивного редактора, не production-снимок или import API.

Файл предыдущего этапа без plans читается без изменения его checksum и без
записи миграции. Хранилище, fsync, previous и контроль версии остаются прежними.
Старый код после добавления plans не сможет прочитать новый черновик:
**откат кода не должен удалять новые планы**. Сначала сверить сохранённую копию;
восстановление старых данных — отдельное осознанное действие, не автоматический downgrade.

POST preview принимает token, draft, date (YYYY-MM-DD), использует прежний лимит
формы и авторизацию LuCI. Ответ: ok, active=false, clock_basis=civil, date,
selected_schedule, events. Событие содержит date, time, origin_date, schedule_id,
row_id, kind=main/pre, media. UTC и обещание фактического запуска отсутствуют.
Интервал ответа — только один день; расчёт учитывает предзвонок следующего дня.

## Проверки

12 host-групп проверяют високосные и вековые даты, края 0001/9999, переход
суток/года, тихие дни, отключённые строки, ссылки и совместимость.
Native crash-тесты хранилища используют полный годовой payload.
В браузере на локальном настоящем Lua-бэкенде проверены назначение, сохранение,
reload и предпросмотр 07:58/08:00. Аппаратные результаты фиксируются отдельно;
это не проверка reboot/питания, DST или автоматического запуска.

На MR3020 прошли те же 12 календарных групп и по 8 точек прерывания записи на /tmp и постоянном разделе. Установленная страница и исходные пользовательские данные проверены по SHA256; core/demo и live topics сохранены. Владелец подтвердил раскраску и сохранение после reload через LuCI. Подтверждение предпросмотра на целевой странице остаётся отдельной проверкой.

Основной способ назначения — цветные кисти расписаний и раскраска дат мышью с зажатой левой кнопкой; на сенсорном экране — нажатиями. «Тихий день / ластик» снимает назначения. Диапазоны скрыты в разделе «Дополнительно». Кнопка явно показывает отсутствие изменений; ожидание запроса ограничено 15 секундами. После потери ответа на сохранение требуется сверка, автоматического повтора нет.

Плашка дежурного показывает состояние сохранения, режим подготовки, отсутствие активного следующего звонка, ревизию тестового интерфейса и установленные версии пакетов из opkg. Это не мониторинг живого исполнителя: автоматического исполнителя пока нет. Отсчёт появится только для активного плана; отсутствие метаданных пакета обозначается явно.

Версия модуля начинается с 5.0.0; формат major.minor.patch, последующие мелкие исправления увеличивают patch. Источник версии — pkg-schoolbell/CONTROL/control; инженерный payload переносит её отдельно от метаданных установленного ядра. Разделы открываются вкладками без потери правок. Плашка сворачивается, часы сравниваются по эпохе, а не по часовому поясу. При расхождении более 5 с предлагается штатный LuCI; часы самостоятельно не меняются. Журнал различает пользователя/модуль/систему, хранит до 16 КиБ, до 24 КиБ с временной записью. Записываются серверные операции, не каждое движение мыши; записи могут потеряться при аварии питания. Это не полный syslog.

Schoolbell 5.0.1: закреплённый за расписанием цвет из 16 мягких оттенков, ручной выбор и сохранение; цвет согласован в списке, календаре и предпросмотре. Текст журнала выровнен влево; ссылка настройки часового пояса независима от синхронизации часов. Старый черновик не перезаписывается при чтении; цвета материализуются только при явном сохранении. Совпадение смещений не доказывает совпадение географических зон/DST.

Откат на 5.0.0 после сохранения color несовместим с его строгой схемой. Команды отката проверяют, что исходный черновик не изменился; новые пользовательские данные не удаляются автоматически.

В 5.0.2 настройка зоны выполняется внутри вкладки «Настройки» и требует отдельного подтверждения. Зона меняется для всего роутера; UTC-эпоха часов не устанавливается. Старые ссылки LuCI из описаний предыдущих этапов больше не используются. Палитра обновлена, сохранённые числовые ID цветов остаются прежними.

В 5.0.3 исправлена фиксация UCI: `-P` запрещает commit в целевой версии, поэтому commit использует `-p`. Успех требует изменения SHA256 файла system. Изолированная регрессия `packages/schoolbell/tests/test_timezone_target.lua` проверяет файл после закрытия staging и повторное чтение в новом staging; не вызывает system reload и не меняет живую конфигурацию.

## Оперативное управление 5.0.4

Mute сохраняется отдельно от черновика и запрещает ручной/тестовый звук роутера. Активный исполнитель проверяет отмену раз в 100 мс; сетевое время и планирование ОС не дают жёсткой гарантии задержки. UI ждёт исчезновения блокировки до подтверждения остановки. Снятие Mute не воспроизводит пропуски. Кнопка звонка использует сохранённую ручную мелодию; test по умолчанию, каталог test/0–4. Настройки предзвонка и режима сохраняются вместе с черновиком. По расписанию — один ежедневный набор, quiet по умолчанию; по годовому плану — назначения датам, отсутствующий год тихий. Автоисполнитель ещё не подключён. Публичное демо не запускает роутер; Mute моделируется локально.
