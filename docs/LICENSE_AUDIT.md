## 33 сторонние зависимости

[Полная таблица версий и лицензий](LICENSE_DEPENDENCIES.md) получена из фактических
control-файлов IPK. Все 33 SHA-256 совпали с lock; 32 поля License совпали дословно.
У `luci-lib-jsonc` License отсутствует; lock честно содержит `unspecified`.
Исходник [jsonc.c ревизии 712bc8e](https://github.com/openwrt/luci/blob/712bc8e/libs/luci-lib-jsonc/src/jsonc.c)
содержит Copyright 2015 Jo-Philipp Wich и Apache-2.0; Makefile той же ревизии также
содержит Apache-2.0. SHA-256 полученного jsonc.c:
`c884f135b9f214713d38c3fa087e9a412bbe09b5ea2f0f2b651970a4e67fa1a0`.
Это дополнительное свидетельство, а не переписанное поле бинарного пакета.
Воспроизводимость именно бинарника из этого исходника в аудите не доказана.

В payload всех 33 IPK не найдены отдельные файлы с license/copying/notice/copyright
в имени. Это поиск имён, не доказательство отсутствия всех уведомлений внутри файлов.
В корне комплекта — IPK, README, manifest, lock, check.sh и SHA256SUMS; отдельного
набора текстов лицензий, атрибуций и соответствующих исходников нет. Manifest
фиксирует URL бинарников и краткие License, но не исполняет все условия лицензий.
libc и kernel — требования firmware, не дополнительные IPK комплекта; их статус
нужно учитывать отдельно при распространении самой прошивки. OEM firmware не входит
в этот аудит; ссылка в Pages не является разрешением зеркалировать OEM-архив.

Для релизного комплекта требуется сопоставить каждый бинарник с точными исходниками,
патчами, конфигурацией и рецептом сборки; собрать уведомления и тексты лицензий.
Для GPL/LGPL определить и выполнить применимый способ предоставления исходников
и остальные условия; не считать URL бинарного feed достаточным. Сверять точные
редакции и исключения, особенно неоднозначные `GPL-2`, `GPLv2`, `LGPL-2.1` и GCC exception.
Опорные первичные тексты: [GPLv2 §3](https://www.gnu.org/licenses/old-licenses/gpl-2.0.html),
[Apache-2.0 §4](https://www.apache.org/licenses/LICENSE-2.0).
Для MIT/ISC/Zlib также нужны применимые исходные уведомления; один ярлык не заменяет текст.

## Штатные мелодии и NOTICE

Байты всех шести MP3 привязаны к исходному коммиту и SHA-256 в
[manifest](../assets/melodies/manifest.json). По сообщению владельца 2026-10-31,
`0.mp3`, `1.mp3`, `2.mp3`, `3.mp3` записаны с дискретного выхода микроконтроллера
«Школьника-2» (не ЦАП) и с тех пор не менялись. Это свидетельство владельца;
исходная прошивка, нотные данные и независимое сравнение с «Школьником-2» не получены.
`4.mp3` и `test.mp3` прямо исключены владельцем из этого происхождения.
Позже владелец уточнил: 0–4 — его записи известных мелодий; для 4.mp3 источник —
отрывок из фильма «Усатый нянь». Поэтому 4.mp3 не приписывается микроконтроллеру;
права на композиции и использованную запись остаются отдельным вопросом.

| Файлы | Что известно | Что ещё требуется |
| --- | --- | --- |
| 0–3.mp3 | Запись выхода «Школьника-2», по свидетельству владельца | Композитор/произведение, источник нот или прошивки, права на аранжировку и запись, условия распространения |
| 4.mp3 | По уточнению владельца: отрывок из фильма «Усатый нянь», неизменные байты из Git | Точная идентификация фрагмента, авторы, права на музыку/запись и условия использования |
| test.mp3 | Исторический тестовый файл, неизменные байты из Git | Источник, содержание/авторство, правообладатель и условия использования |

Имена в melodies.json — исторические подписи, не проверенная идентификация произведений.
Не выводить статус public domain только из слова «Бах» или «Князь Игорь».
Изменение тембра само по себе не закрывает пробелы происхождения композиции и записи.

Первоначальный пакетный NOTICE был неполным. Теперь сборщики доставляют текущие
LICENSE/NOTICE, отдельную область действия и аудиоуведомление с правильным путём
media-manifest.json. [Доставка и проверенные пробелы](LICENSE_DELIVERY.md).

## Открытые пункты перед распространением

Владелец 2026-10-31 поручил оформить MIT для собственного кода. Добавлен стандартный [LICENSE](../LICENSE); [область действия и исключения](LICENSING.md) закреплены отдельно.

- L1: выполнено для собственного кода и документации schoolbell по решению владельца: MIT и явная область действия; исключения не перелицензированы.
- L2: собрать точные источники и лицензионные уведомления всех зависимостей,
  проверить условия GPL/LGPL/GCC exception и включить комплект материалов в релиз.
- L3: выполнено для timezone-данных: ревизия, исходный хеш/заголовок и преобразование сверены; Apache-2.0 доставляется в Pages.
- L4: установить происхождение/права каждого аудиофайла и композиции, особенно 4/test;
  при отсутствии подтверждений согласовать замену или исключение из распространения.
- L5: доставка собственного LICENSE/NOTICE/области и известных уведомлений выполнена и проверена в IPK/native/Pages/комплекте. Полный релизный набор зависит от закрытия L2/L4.

Аудит выполнен; L1/L3 и доставка L5 выполнены; L2/L4 остаются открытыми. MIT применяется только в
описанной области. По решению владельца штатные мелодии сохраняются без изменений.

Проверки аудита: полный `make all` — PASS в WSL; `git diff --check` — PASS. Метаданные, control и payload пересобранного IPK идентичны принятому кандидату 5.1.28. Хеши всех штатных MP3 сохранены. Это host-проверки, не аппаратная приёмка.
