# Установка и восстановление: выбор способа

[English](INSTALLATION.en.md) · [Релизы](RELEASING.md) · [План мастера](SETUP_WIZARD_PLAN.md)

Актуально на 25.11.2026: Школьник 5.1.127, мастер 0.3.0. Оба способа поддерживаются:
графический мастер для пошаговой работы и консольный комплект для специалистов.
Наличие маршрута на стартовом экране не означает готовность прошивки.

## Что уже можно выполнить

| Задача | Графический мастер | Консольный способ |
| --- | --- | --- |
| OEM → OpenWrt 19.07.9 | Передача, загрузка и DHCP проверены 25.11.2026 | Setup.cmd; подтверждён конечный результат установки, непрерывный цикл ещё требует проверки |

| OEM → та же заводская Build250625 | Механизм реализован; OEM → OEM этим GUI отдельно не проверен | Setup.cmd -RestoreFactory; аппаратно проверено |

Проверенный профиль прошивки — **TL-MR3020 (EU) Ver. 3.30**. Не переносите результат
на другие регионы/ревизии. OpenWrt показывает v3 без доказательства точной ревизии:
проверьте наклейку. Build250625 — поддерживаемая заводская версия, а не обещание
вернуть любую исходную версию конкретного устройства.

## Общая подготовка

Нужны роутер с питанием, отдельный USB–Ethernet-адаптер и RJ45, Windows 11 x86_64,
PowerShell 7 и права администратора для изменения сети. Сохраните важные настройки
и проверенную копию на ПК. Копии могут содержать пароли — не прикладывайте их к релизу.
Для пакетов нужен пароль root; для входа в OEM — пароль администратора TP-Link.
Для передачи через Reset пароль не нужен. Wi-Fi-ключ не заменяет пароль администратора.
Выберите именно выделенный адаптер по имени и описанию; не ориентируйтесь на старый ifIndex.

## Работа через GUI

Распакуйте весь архив мастера и запускайте schoolbell-setup-wizard.exe. Служебные
файлы рядом с EXE необходимы; статическая Qt-сборка не означает единственный файл.
Комплект пакетов — отдельный ZIP рядом с EXE. [Пошаговое руководство GUI](../tools/setup/gui/README.md).

Оба образа встроены. Выберите операцию, модель и выделенный адаптер; выполните
проверку подключения и подтвердите запуск/UAC. Только после **READY** отключите
питание нужного роутера, зажмите Reset и подайте питание. Отпустите Reset после
начала передачи, затем оставьте питание включённым до загрузки. Дождитесь
восстановления сети и проверьте интерфейс/версию устройства.

25.11.2026 этот порядок проверен для возврата OEM и установки OpenWrt. Затем
подтверждена свежая установка Школьника из ZIP. Смена SSH-ключа после прошивки
потребовала ручной сверки и замены старой записи: GUI ещё не делает это сам.
Не отключайте проверку ключей. Чистая Windows и точный релизный ZIP требуют приёмки.
Резервная копия перед прошивкой необязательна; она остаётся отдельной операцией.

## Работа через консоль

Используйте полностью распакованный комплект, соответствующий выбранному профилю.
[Установка OpenWrt и пакетов](../tools/setup/README.md) и
[возврат заводской системы](../tools/setup/RECOVERY.md) содержат команды и восстановление после ошибки.

В PowerShell 7 из папки комплекта сначала выполните нужный DryRun:

```powershell
.\Setup.cmd -DryRun
# Либо для OEM:
.\Setup.cmd -RestoreFactory -DryRun
```

После успешной проверки, в окне администратора, запустите соответственно
`.\Setup.cmd` или `.\Setup.cmd -RestoreFactory`. Консольный OpenWrt-маршрут сейчас
также предлагает установку пакетов; отдельный firmware-only ещё предстоит выделить.
Для OEM комплект должен содержать проверенный firmware/oem-recovery.bin.

Только после READY отключите питание нужного роутера, зажмите Reset и подайте
питание. Отпустите кнопку после начала передачи. Питание не прерывайте до загрузки.
TRANSFER COMPLETE означает передачу, не доказательство записи/загрузки.
После OpenWrt проверьте LuCI и версию; после OEM — заводской интерфейс и Build250625.
Пароль/настройки OEM могут сохраниться. Сброс на уже загруженном роутере — отдельное
действие с удалением настроек; он не равен Reset при подаче питания.

## Как поддерживается руководство

При изменении маршрута обновляются эта таблица, подробное руководство, TODO,
CHANGELOG RU/EN и заметка выпуска. Ссылки на тесты и аппаратные результаты сохраняются
в [протоколе приёмки](acceptance/ACCEPTANCE_RUN.md). Не заменяйте дату старого опыта
версией новой сборки. Публикация релиза требует отдельной проверки его точных файлов.

### Прошивка через мастер: порядок действий

1. Выберите выделенный USB–Ethernet и подтвердите TL-MR3020 EU v3.30. Нажмите «Проверить подключение».
2. После успешной проверки нажмите «Начать восстановление» или «Установить OpenWrt». Подтвердите действие и UAC. Сеть и сервер подготавливаются автоматически.
3. Только после «Сервер готов» следуйте появившейся инструкции с изображением Reset.
4. Следите за постоянной панелью результата: передача, ожидание записи и восстановление сети происходят без дополнительных нажатий.
5. Нажмите «Открыть интерфейс роутера», войдите и сверьте указанную версию. Отмечать результат в мастере не требуется; открытие ссылки не считается автоматическим подтверждением загрузки.

Справка и диагностика свёрнуты. Отдельная подготовка сети — диагностическая операция, не обязательный шаг прошивки. Если остались временные настройки, основное действие предложит восстановление сети.

Результаты передач хранятся по UUID. Новый экземпляр не показывает чужую завершённую передачу как текущую. Общий защищённый журнал нужен только для координации и аварийного восстановления адаптера; его нельзя удалять для обхода незавершённой операции. Helper пока консервативно допускает только одну сетевую операцию на компьютере, поскольку TFTP использует фиксированные адреса и порты.

Ожидания запроса роутера (03:00) и записи/загрузки (01:30) сопровождаются обратным отсчётом. Ноль не означает успех: мастер ждёт результата helper. Для DHCP точный срок не обещается.

«Открыть лог действий» открывает один текущий файл в стандартном текстовом редакторе Windows. В него дописываются выбор интерфейса, проверка и этапы операции; повторные нажатия не создают копий. Новый сеанс получает отдельный файл, прежние логи сохраняются в каталоге данных мастера. Если редактор не отслеживает внешние изменения, перечитайте файл для просмотра новых строк.

## Повторная установка GUI / GUI reinstall

Выберите ZIP, подключение и пароль root, затем «Установить Школьник». Проверка и полная копия необязательны. Установка поверх и повтор после ошибки доступны без нового сеанса. Каждая попытка сохраняется отдельно. При смене SSH-ключа подтвердите показанный отпечаток в форме. Совместимость конкретных пакетов определяет opkg; его ошибка не запрещает следующую попытку.

После попытки установки адрес http://192.168.1.1/cgi-bin/luci/admin/schoolbell показан ссылкой в форме и записан в протокол. После ошибки доступность интерфейса не подтверждена.

### Проверка 26.11.2026

Пользователь подтвердил успешную установку комплекта 5.1.127 поверх той же версии
и открытие Школьника как по кнопке, так и по текстовой ссылке в форме.
Это не подтверждение опыта с обрывом записи или неверным паролем; эти проверки
остаются отдельными. Рабочий стенд в этом этапе не изменялся.

Пароль администратора OpenWrt — пароль пользователя root, используемый и LuCI,
и SSH. После новой установки OpenWrt задайте его через LuCI до установки комплекта.
В мастере это указано в «OpenWrt · Комплект → Справка → Что понадобится» и в справке
экрана прошивки. Возле поля есть подпись «Пароль root» и подсказка о пароле OpenWrt,
и добавлено напоминание о предварительной установке root через LuCI прямо под полем.

При неверном пароле SSH отклоняет вход. Мастер показывает ошибку подключения
(обычно код 255 / Permission denied), не объявляет успех и оставляет возможность
исправить пароль в том же поле и повторить действие без нового сеанса.
Если неверный пароль введён с самого начала, удалённые команды установки не выполняются.
Эта обработка установлена по коду; отдельный аппаратный опыт с неверным паролем
в данной проверке не выполнялся.
