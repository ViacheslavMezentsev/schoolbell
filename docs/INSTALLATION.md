# Установка и восстановление

[English](INSTALLATION.en.md) · [Начать с релиза](GETTING_STARTED.md) · [Оборудование](HARDWARE.md)

## Выбор способа

| Задача | Графический мастер | Консоль для специалистов |
| --- | --- | --- |
| Установить OpenWrt | Встроенный образ; подготовка адаптера, READY, передача и восстановление сети | [Setup.cmd](../tools/setup/README.md) |
| Вернуть заводскую прошивку | Встроенный OEM Build250625; тот же порядок действий | [Setup.cmd -RestoreFactory](../tools/setup/RECOVERY.md) |
| Установить Школьник | Внешний ZIP; новая установка, установка поверх и повтор после ошибки | `install.py` и инструкция внутри комплекта |

Начните с [руководства по релизу](GETTING_STARTED.md): скачивание, распаковка, пароли, момент нажатия Reset и ожидаемый результат. Подробности — в [справке мастера](../tools/setup/gui/README.md). Для консоли используйте инструкцию именно выбранного архива; исходники репозитория не являются готовым комплектом.

## Поддержка и результаты

Проверенный профиль перепрошивки — **TL-MR3020 EU v3.30**, Windows 11 x64. Другие ревизии требуют своей проверки. Скачанная пара **мастер 0.3.1 / Школьник 5.1.127** прошла установку поверх той же версии и цикл OpenWrt → OEM → OpenWrt → новая установка Школьника с автоматическим восстановлением DHCP. [Протокол](acceptance/wizard-0.3.1-github.md).

OEM → OEM именно этой сборкой, чистая Windows без среды разработки, ручная CLI-установка из ZIP, откат версии с данными и восстановление overlay остаются отдельными проверками. Успех GUI их не закрывает. Пересобранные архивы требуют своей проверки; точная пара и хеши указываются в каждом выпуске.

Полная копия необязательна и не восстанавливается автоматически. Пароль OEM может сохраниться после прошивки; сброс настроек выполняется отдельно. Завершение передачи не подтверждает загрузку: откройте интерфейс и сверьте версию.
