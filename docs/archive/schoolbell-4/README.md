# Исторический архив «Школьник-4»

[English](README.en.md)

Побайтный снимок всех 20 отслеживаемых файлов старого schoolbell из коммита
`c4bbecd1bd5136051cc12858801fb9bed7222cc2`. История Git сохранена без переписывания.
Имена, содержимое и режимы файлов сохранены; контрольные суммы — в manifest.json.
README и manifest добавлены при архивировании, в исходный снимок не входят.

Это исторические материалы, не действующее приложение. CGI нельзя запускать
или включать в установочный пакет. Архив не публикуется в Pages и не используется
как начальные настройки нового модуля. Будущие сборщики используют явный список
источников, а не копирование всего репозитория.

settings.json, plan.json, schedules.json и log.txt уже находились в публичной
истории: просмотрены при архивировании, содержат старые настройки, расписания
и журнал действий. Паролей, ключей и адресов устройств в них не обнаружено.
Это не резервная копия текущего стенда. Base64 в schedules.json — кодировка
строк расписания, не шифрование. Новые реальные данные сюда не добавляются.

Музыка и сторонние JS сохранены с исходным происхождением. Общая лицензия
старого репозитория явно не задана; архивирование не предоставляет новых прав
на распространение. Перед выпуском нового комплекта проверяется NOTICE каждого
стороннего компонента и мелодий. Не назначать всем файлам новую лицензию автоматически.
