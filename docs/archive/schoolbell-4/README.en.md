# Schoolbell-4 historical archive

[Русский](README.md)

Byte-for-byte snapshot of all 20 tracked files at schoolbell commit
`c4bbecd1bd5136051cc12858801fb9bed7222cc2`. Git history is not rewritten.
Paths, contents and file modes are preserved; manifest.json records SHA-256
and sizes. The READMEs and manifest are new archive metadata.

Not a runnable or supported application. Do not execute CGI, package this tree,
publish it through Pages, or use its settings as new installation defaults.
Future builders must explicitly select sources instead of copying the repository.

The settings, plan, schedules and log were already public. Review found historical
settings and events, not passwords, keys or device addresses. Base64 schedule
rows are encoding, not encryption. This is not a backup of the current bench;
never add fresh device data here.

Audio and third-party JavaScript retain their provenance. The old repository
has no explicit overall license; preservation does not grant new redistribution
rights. Review component and media notices before a release; do not relicense
the archive wholesale.
