# Экспорт выбранных планов с устройства

[English](PORTABLE_PLAN_EXPORT_DEVICE.en.md) · [Импорт](PORTABLE_PLAN_IMPORT.md)

Кандидат5.1.21, проверки на хосте. На устройство не установлен.

В «Календарь → Экспорт календарных планов .sbp» выбрать один или несколько
сохранённых планов и нажать «Скачать выбранные планы». Несохранённые правки
сначала сохранить или явно отменить; автозвонки должны быть выключены.

В файл входят диапазоны/назначения, используемые расписания, цвета, все строки
(включая выключенные), параметры и мелодия предзвонка. Штатные мелодии описаны
точным SHA/размером; пользовательские включены байтами, одинаковые файлы не
дублируются. Ручной звонок, звук/громкость, сеанс, сеть и часы не переносятся.
Экспорт не меняет черновик или активный план. Для полной копии остаётся .sbb.

POST plan-export принимает строгий JSON {selected:[id,...],revision:SHA256},
до4096байт,1–8 выбранных планов. Сессия администратора LuCI и Bearer CSRF
обязательны; GET и устаревшая ревизия отвергаются. Файл полностью собирается
и проверяется в частном /tmp до отправки заголовков HTTP. Источник защищён
общими замками player→editor→media; перед скачиванием они освобождаются.
Проверяются только зависимости выбранных планов, не посторонние мелодии.

Расход /tmp ограничивается длиной контейнера≤2125906байт; admission резервирует
две длины файла +128КиБ +max(1МиБ,10% tmp). Аудио читается блоками≤16КиБ,
SHA вычисляется через временный файл, не накоплением аудио в строке Lua.
Нормальное завершение и исключение удаляют собственный временный каталог.
SIGKILL/обрыв питания может оставить временный каталог до очистки /tmp;
это не постоянные данные. Устройство не получает периодической службы очистки.

Браузер ограничивает скачивание180сек, проверяет MIME, длину, magic и неизменность
локального снимка/сеанса. При ошибке управление восстанавливается, запрос сам
не повторяется. Полные внутренние SHA повторно проверяет импортёр .sbp.

TC-181: хостовый полный перенос с настоящим MP3 в другое пустое хранилище,
проверка зависимостей/байтов/свободного слота, сохранность источника, ошибки
ревизии/выбора/места/записи, ранний CSRF, освобождение замков до ответа и сбой
получателя, UI усечения/смены черновика. Pages по-прежнему экспортирует только
штатные мелодии и явно отклоняет .sbp с пользовательским аудио на preview.

Целевые LuCI, пиковый RSS, большие файлы и медленный клиент ещё не проверены.
Следующий шаг: после резервной копии отдельно установить и проверить экспорт
плана с пользовательской мелодией; импорт в изолированное хранилище не должен
заменять действующие данные или включать автозвонки.
