## Validation boundary

Checks SBPLAN1 framing, bounds, manifest/payload hashes, strict manifest JSON,
fields/types, unique IDs/files, permitted paths/order, user-to-file catalogue links
and payloads unreferenced by catalogue entries. Calendar currently receives only
bounded strict JSON validation.

Result admitted=false means parsed bytes, not permission to save. The next layer
must validate calendar semantics and complete melody reachability, installed bundled
hashes, actual timezone, MP3/duration, existing-data conflicts, quotas and operation
admission. Corpus audio is synthetic and is not evidence of valid MP3 support.

The existing core strict decoder limits apply:16 KiB, depth8,4096 nodes. Valid
manifest/calendar schema shapes fit these structural limits. No new core JSON API.
JS scans keys/escapes/surrogates/bounds before JSON.parse; JSON.parse alone silently
loses duplicate keys.

## Side-effect-free API

Lua decode(source,hash_factory,sink), JS decode(source,hashFactory,sink): source
returns nonempty chunks <=16384 bytes and nil/null at EOF. Lua errors use a second
return or exception; JS rejects a Promise. Factory creates an independent SHA256
context with update(chunk),finish() returning64 lowercase hex digits. This trusted
injected adapter needs separate integration validation. Lua uses existing small
metadata SHA for manifest and injected streaming hashes for payloads.

Optional sink(name,chunk) receives tentative bytes only; false/throw aborts. JS is
async, Lua synchronous; scheduling/cancellation belongs elsewhere. Success returns
manifest, original calendar bytes, bytes, admitted=false; failures throw. No sink
success notification occurs before complete validation.

encode(raw_manifest,source_for,hash_factory,emit) validates descriptors, emits
header/manifest/payload chunks <=16384, checks exact file sizes, calendar JSON,
hashes and per-source EOF. Returns byte count only after success. Late errors leave
partial tentative output: caller must discard it all. Neither codec writes files,
uses network, runs audio or publishes storage. An exception is not caller rollback.

manifest(raw) checks descriptors only, returning manifest,total in Lua or
{manifest,bytes} in JS. File existence is not checked. Whole audio strings are not
required; target peak RSS and adapter memory remain unmeasured.

## Reproducible tests

make test-schoolbell and make all include the shared corpus through the existing
media host runner (Lua5.1, Node, Python, host C helper). Standalone:

```sh
python3 packages/schoolbell/portable-plan/test.py
```

Lua5.1/Node must be on PATH; host bit helper accelerates metadata SHA. Python
hashlib constructs bytes independently from both codecs. A pinned textual golden
fixture records raw bytes and full archive hash; both encoders must reproduce it.
62 vectors/175 stream cases per language cover1/7/16384-byte chunks, metadata/media
bounds,2 MiB media total, headers, truncation/trailing, hashes, escaped duplicate
keys, invalid UTF-8/surrogates, paths/order, missing/orphan payload and source/sink/hash
failures. Round trips are checked against independently generated bytes, not alone.

TC-168–174 are not fully accepted: dependency/admission, UI and durable recovery now have host coverage; target integration and power-loss acceptance remain separate. No installation, audio or power-loss experiment was performed in this stage.
