# Начать с файлов релиза

[English](GETTING_STARTED.en.md) · [Оборудование](HARDWARE.md) · [Руководство Школьника](user/USER_GUIDE.md)

## 1. Скачать нужные файлы

Откройте [Releases проекта](https://github.com/ViacheslavMezentsev/schoolbell/releases). Выберите выпуск, прочитайте его ограничения и раскройте **Assets**. Если опубликованных выпусков ещё нет, установочные файлы на этой странице ещё не доступны; ZIP исходников их не заменяет.

| Файл | Что с ним делать |
| --- | --- |
| `schoolbell-setup-wizard-v<версия>-windows-x86_64.zip` | Распаковать целиком в отдельную папку на компьютере. |
| `schoolbell-v<версия>-openwrt-19.07.9-ramips-mt76x8-mipsel_24kc.zip` | Оставить ZIP, положить рядом с EXE мастера или выбрать его кнопкой с папкой. |
| `SHA256SUMS`, подпись сумм и публичный ключ/инструкция проверки | Использовать для проверки целостности и происхождения скачанных файлов по инструкции конкретного выпуска. |
| `.ipk`, сведения о сборке и исходники | Дополнительные материалы для специалистов; для GUI достаточно двух ZIP и материалов проверки. |

**Source code (zip/tar.gz)** — исходники проекта, а не готовый мастер. Версии мастера и Школьника различаются: используйте пару, указанную в описании выпуска. Образы OpenWrt и поддерживаемой заводской прошивки уже входят в мастер; отдельно искать их не нужно.

Контрольная сумма позволяет сверить байты файла, а подпись — проверить, кем опубликованы суммы. Подписанный Git-коммит не является подписью скачанного ZIP. Конкретный формат подписи, отпечаток доверенного ключа и команды должны быть приложены к выпуску; отсутствие этих файлов не означает, что подпись проверена. Проверку SHA-256 можно выполнить командой PowerShell `Get-FileHash -Algorithm SHA256 'путь-к-архиву.zip'`, сравнив результат с одноимённой строкой `SHA256SUMS`.

## 2. Подготовить компьютер и роутер

Нужны [оборудование из списка](HARDWARE.md), **Windows 11 x64, PowerShell 7, Windows OpenSSH Client** и права администратора. Эти системные компоненты устанавливают заранее; Qt, Python и среда разработки для запуска распакованного мастера не нужны. Проверка запуска на полностью чистой Windows остаётся отдельной приёмкой, а не заявленным результатом.

Подключите Ethernet-порт роутера к выделенному USB–Ethernet-адаптеру компьютера и подайте питание. Основное подключение компьютера не используйте вместо выделенного адаптера. Перед перепрошивкой сохраните нужные данные: мастер может заменить установленную систему. Полная копия доступна для подходящей OpenWrt, но не обязательна для прошивки; настройки OEM при необходимости сохраняют в заводском интерфейсе.

Запустите `schoolbell-setup-wizard.exe` из распакованной папки. Не переносите один EXE отдельно от остальных файлов. Выберите нужное действие.

## 3. Выбрать сценарий

### Установить OpenWrt на роутер

1. Сверьте на корпусе **TL-MR3020 EU v3.30**, выберите выделенный адаптер и выполните проверку подключения.
2. Нажмите основную кнопку установки, подтвердите действие и запрос Windows на права администратора.
3. Дождитесь **«Сервер готов» / READY**. Только тогда отключите питание нужного роутера, зажмите WPS/RESET и подайте питание. После начала передачи отпустите кнопку.
4. Дождитесь окончания передачи, ожидания записи и восстановления сети компьютера. Питание роутера не отключайте. Передача файла сама по себе ещё не означает успешную загрузку.
5. Откройте интерфейс роутера кнопкой мастера, убедитесь, что открылась OpenWrt/LuCI, задайте пароль root. Затем перейдите к установке комплекта.

### Установить или повторно установить Школьник

1. Выберите ZIP из списка рядом с EXE либо кнопкой папки. Сверьте показанные путь и версию.
2. Выберите подключение и введите пароль **root**, заданный в LuCI. Если нужно, проверьте устройство и сохраните копию — это отдельные необязательные действия.
3. Нажмите «Установить Школьник» и подтвердите установку. Можно установить поверх той же версии или повторить после ошибки; сообщение об ошибке нужно прочитать перед повтором. При смене SSH-ключа после перепрошивки сверьте устройство и подтвердите новый ключ в форме.
4. Дождитесь **INSTALL VERIFIED**, откройте ссылку или кнопку Школьника. Проверьте версию, выключенные автозвонки и громкость. При неверном пароле исправьте его в форме и повторите действие.

Интерфейс: `http://<адрес-роутера>/cgi-bin/luci/admin/schoolbell`. Адрес показывает мастер; после чистой установки обычно используется `192.168.1.1`. Далее настройте план и часы по [руководству](user/USER_GUIDE.md). Установка не включает автозвонки.

### Восстановить заводскую прошивку

Выберите восстановление заводской системы и пройдите те же этапы подготовки, READY, Reset и ожидания, что для OpenWrt. Откройте интерфейс TP-Link и проверьте **1.8.0 0.9.1 v0001.0 Build 250625 Rel.56805n**.

Прежний пароль администратора TP-Link может сохраниться. Это не пароль root OpenWrt и не Wi-Fi-ключ с наклейки. При забытом пароле нужен [отдельный сброс настроек на загруженном роутере](../tools/setup/RECOVERY.md); зажатие Reset при подаче питания для передачи образа его не заменяет.

## Если что-то не получилось

Прочитайте состояние операции и откройте «Лог действий». Пока идёт запись, не отключайте питание: остановка мастера не отменяет уже начатую запись роутером. Не запускайте несколько мастеров на одном адаптере одновременно. При оставшихся временных сетевых настройках используйте предложенное восстановление сети. Для сообщения об ошибке приложите текст результата без паролей и резервных копий.
