## Предварительная поставка примера

`make build-schoolbell` создаёт `out/modbus-schoolbell_0.0.1_all.ipk`;
версия задаётся отдельно через `SCHOOLBELL_VERSION`. Сборка входит в `make all`.
Это media-only preview: `/usr/share/modbus-schoolbell/melodies/test.mp3` и NOTICE,
без служб, cron, player, конфигурации и автоматического звука. Зависимость от
будущего API появится с функциональным портом; сейчас совместимость не заявлена.

[Исходный набор мелодий](../../assets/melodies/README.md):
шесть MP3; в IPK только самый короткий test.mp3 (около 3,28 с, 13104 байта).
CI проверяет manifest и точный состав IPK с Python 3.8+ на машине сборки.
На роутер preview-пакет не установлен. Ручное воспроизведение его MP3 через
madplay подтверждено пользователем; это не проверка функционального пакета.

Для первого опыта: подключить колонки с минимальной громкостью, затем проверить
наличие player, аудиоустройство и USB-питание. После отдельного согласования —
одно воспроизведение короткого файла и очистка временных файлов. Установка player,
изменение mixer/драйверов и звук не выполняются одной лишь сборкой IPK.

ТЗ 1.3 принимает владение аудиоисполнителем, FIFO/сроками/отменой из ядра; добавлены автономные зависимости и постоянное хранение. Ручной звук подтверждён, функциональная поставка ещё не реализована.

Полоса места: до 75% включительно — обычный цвет, >75% — жёлтый, >90% — красный. Процент относится ко всему показанному накопителю, не только квоте мелодий. Запас и ограничения приёма файлов не изменяются.

С 5.1.24 отдельные пределы числа строк сняты. Сохраняются размер черновика 12288 байт и бюджеты расчёта событий; вместимость зависит от данных. Большие планы могут не импортироваться старыми версиями — используйте совместимую версию устройства и Pages.

Системная установка времени 5.1.25: Lua clock_set формирует числовую UTC-дату для штатного date и проверяет exit/readback. Источник совместимого механизма — [LuCI 19.07 setLocaltime](https://github.com/openwrt/luci/blob/openwrt-19.07/modules/luci-base/root/usr/libexec/rpcd/luci); RPC не вызывается, sysfixtime не перезапускается. Гарантия абсолютной точности и сохранение часов после питания не заявляются.
