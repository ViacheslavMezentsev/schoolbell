# Школьник v5.1.127 / Schoolbell v5.1.127

> Черновик описания. Тег и публичные артефакты этим документом не создаются.
> Draft notes; this document creates neither a tag nor public assets.

## Русский

- Приведены к общему виду кнопки, отступы и фокус клавиатуры, улучшены обе темы и узкий экран.
- Обновлены пояснения и Шпаргалка; панель сохранения появляется при правках.
- Медиатека получила компактную справку; положение переключателя определяется на свежей системе.

Целевой профиль: OpenWrt 19.07.9, ramips/mt76x8, mipsel_24kc. Отдельные аппаратные
проверки выполнены на TL-MR3020 EU v3.30. Не применять комплект к другим ABI.

Планируемые файлы: полный ZIP пакетов, IPK приложения, SHA256SUMS и подпись;
совместимый Schoolbell Setup Wizard — отдельным ZIP Windows x86_64 с собственной версией.
Новый формат полного ZIP пока является кандидатом. Мастер 0.2.0 обнаруживает ZIP рядом с EXE и проверяет его локально.
Host CLI prepare/install/verify для свежей OpenWrt реализован и проверен локально,
включая копию вне устройства; аппаратная приёмка ещё не выполнена.

Подтверждено обновление через GUI 5.1.124 → 5.1.127, выключенные автозвонки,
сохранённые настройки звука/плана, повторная проверка актуальной версии и копия MTD/overlay.
Это не приёмка свежей установки нового ZIP или перепрошивки через GUI.
До публикации остаются аппаратная проверка ручной/свежей установки и GUI ZIP,
подготовка исходников и лицензий зависимостей/аудио и подписи артефактов.

## English

- Consistent controls, spacing and keyboard focus; both themes and narrow layouts improved.
- Updated explanations/help and a save bar shown for edits.
- Compact media help; the physical mode switch can be detected on fresh installations.

Target: OpenWrt 19.07.9, ramips/mt76x8, mipsel_24kc; separate hardware checks used
TL-MR3020 EU v3.30. Do not use with other ABIs.

Planned assets: full package ZIP, application IPK, SHA256SUMS/signature and a separately
versioned Windows x86_64 Schoolbell Setup Wizard ZIP. The new bundle is still a candidate;
wizard 0.2.0 discovers sibling ZIP files and validates them locally. Host prepare/install/verify for fresh OpenWrt
is implemented and tested locally with off-device backup; hardware acceptance is pending.

GUI upgrade 5.1.124 to 5.1.127, automation off, sound/plan preservation, already-current
verification and MTD/overlay backup passed. Fresh/manual installation of the new ZIP and
GUI flashing are not accepted by those results. GUI ZIP and fresh/manual hardware acceptance,
corresponding sources, dependency/audio licensing and artifact signatures remain release gates.
