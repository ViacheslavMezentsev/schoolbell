# Школьник 5.1.127 · Мастер установки 0.3.2

Первый предварительный выпуск для самостоятельной сборки музыкального школьного звонка.

Мастер поможет установить OpenWrt, установить Школьник или вернуть заводскую прошивку роутера.

## Что понадобится

**TP-Link TL-MR3020 EU v3.30**, компьютер с Windows 11 x64, отдельный USB–Ethernet-адаптер и сетевой кабель. Для звонков — USB-аудиокарта и колонки. [Список оборудования и подготовка компьютера](https://github.com/ViacheslavMezentsev/schoolbell/blob/9aa047b5003e67445c242821b2d3d76fa91dcd9f/docs/HARDWARE.md).

## Как начать

1. Скачайте **schoolbell-setup-wizard-v0.3.2-windows-x86_64.zip** и распакуйте целиком.
2. Скачайте **schoolbell-v5.1.127-openwrt-19.07.9-ramips-mt76x8-mipsel_24kc.zip**. Оставьте его ZIP рядом с мастером или выберите кнопкой папки.
3. Запустите **schoolbell-setup-wizard.exe**, выберите действие и следуйте подсказкам.

[Пошаговое руководство](https://github.com/ViacheslavMezentsev/schoolbell/blob/9aa047b5003e67445c242821b2d3d76fa91dcd9f/docs/GETTING_STARTED.md) · [Руководство Школьника](https://github.com/ViacheslavMezentsev/schoolbell/blob/9aa047b5003e67445c242821b2d3d76fa91dcd9f/docs/user/USER_GUIDE.md)

Для установки нужны два ZIP. **SHA256SUMS** и **SHA256SUMS.sig** позволяют проверить файлы: [инструкция](https://github.com/ViacheslavMezentsev/schoolbell/blob/9aa047b5003e67445c242821b2d3d76fa91dcd9f/packaging/release/VERIFY.md), [публичный ключ](https://github.com/ViacheslavMezentsev/schoolbell/blob/9aa047b5003e67445c242821b2d3d76fa91dcd9f/packaging/release/signing-key.pub) и [параметры проверки](https://github.com/ViacheslavMezentsev/schoolbell/blob/9aa047b5003e67445c242821b2d3d76fa91dcd9f/packaging/release/allowed-signers). Автоматические **Source code** — исходники, для установки их скачивать не нужно.

First preview of Schoolbell 5.1.127 and Setup Wizard 0.3.2. The wizard installs OpenWrt, installs Schoolbell or restores stock firmware.

For **TP-Link TL-MR3020 EU v3.30** and Windows 11 x64, with a dedicated USB–Ethernet adapter and cable. Bells also require USB audio and speakers. [Equipment and prerequisites](https://github.com/ViacheslavMezentsev/schoolbell/blob/9aa047b5003e67445c242821b2d3d76fa91dcd9f/docs/HARDWARE.en.md).

Download and fully extract the **wizard ZIP**. Keep the **Schoolbell ZIP** beside the EXE or select it using the folder button. Run **schoolbell-setup-wizard.exe** and follow its instructions.
