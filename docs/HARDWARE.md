# Оборудование и проверенные подключения

[English](HARDWARE.en.md) · [Начать установку](GETTING_STARTED.md) · [Проект](../README.md)

## Роутер и установка

Проверенный профиль перепрошивки и возврата заводской системы: **TP-Link TL-MR3020 (EU) Ver. 3.30**. Питание этой ревизии — USB Type-C. Надпись «TL-MR3020 v3» в программе не доказывает точную ревизию: сверьте наклейку корпуса. Фотографии и границы поддержки — в [списке восстановления](../tools/setup/RECOVERY.md) и [материалах производителя](../tools/setup/vendor/support.md).

Для работы используется OpenWrt 19.07.9. Наличие похожего корпуса, другой ревизии или архива заводской прошивки не означает поддержку мастером. Поддерживаемый возврат — OEM Build250625, а не любая версия, стоявшая на устройстве при покупке.

Для установки через мастер нужны Windows 11 x64, PowerShell 7, Windows OpenSSH Client, права администратора, отдельный USB–Ethernet-адаптер и RJ45. Выделенный адаптер помогает отличить роутер от основного подключения компьютера. Не выбирайте основной сетевой адаптер вместо него.

## Звук

| Проверенная конфигурация | Что известно |
| --- | --- |
| AB13X USB Audio напрямую через OHCI | Серия 100 запусков без отказа процесса; позднее подтверждена слышимость контрольных звонков. |
| C-Media напрямую через OHCI | Серия 100 запусков без отказа процесса. |
| Другой хаб + C-Media USB PnP Sound Device через OHCI | Серия 100 запусков без отказов. |
| Прежний хаб через EHCI | Периодические ошибки запуска USB-аудио; причина не устранена. Не рекомендуем это сочетание для эксплуатации. |

Для повторения системы пока выбирайте прямое OHCI-подключение либо хаб, при котором в **«Метрики → Ресурсы → Аудио»** отображается **OHCI**. Правильное обозначение второго контроллера — **EHCI**. Это тип контроллера USB-маршрута, а не название или сертификат хаба.

Имена AB13X и C-Media — имена обнаруженных устройств, не гарантированная торговая модель. Точная модель проверенного хаба не установлена в публичном протоколе, поэтому рекомендации купить конкретный товар здесь нет. Сам по себе OHCI не доказывает надёжность любого хаба, карты, кабеля и питания.

Подключите активные колонки либо усилитель с колонками. Проверьте ручной звонок, затем предзвонок и основной звонок по расписанию; убедитесь, что их слышно и результат появился в журнале. Успешное завершение проигрывателя само по себе не подтверждает слышимый звук.

[Подробный протокол USB-аудио](PLAYBACK_RELIABILITY.md) содержит измерения и ограничения. Новая рекомендация не закрывает дефект прежнего сочетания EHCI; проверка новых компонентов остаётся отдельной задачей.
