# Исходные мелодии schoolbell

[English](README.en.md)

Перенесены без изменений по поручению владельца из
[schoolbell](https://github.com/ViacheslavMezentsev/schoolbell/tree/c4bbecd1bd5136051cc12858801fb9bed7222cc2).
Ревизия и контрольные суммы находятся в [manifest.json](manifest.json).
В исходном репозитории нет явной лицензии; перенос не назначает новую лицензию
и не утверждает авторство аудио. `melodies.json` сохранён в исходном виде.

| Файл | Имя из исходного списка | Длительность, с (ffprobe) | Размер, байт |
| --- | --- | ---: | ---: |
| 0.mp3 | [Короткая] Время | 10,318 | 41273 |
| 1.mp3 | Шутка Баха | 15,830 | 63321 |
| 2.mp3 | Гостья из XXI | 17,476 | 69904 |
| 3.mp3 | Князь Игорь | 17,006 | 68023 |
| 4.mp3 | Усатый нянь | 20,592 | 82368 |
| test.mp3 | Отдельный тестовый звук, вне melodies.json | 3,276 | 13104 |

Исторические длительности приведены выше; новая обработка их не заменяет.
Текущий полный IPK 5.1.28 и Pages включают все шесть MP3; прежнее описание
минимального pkg-schoolbell с одним test.mp3 больше не описывает текущую сборку.
Суммарный размер исходных MP3 — 337993 байта.

По сообщению владельца 2026-10-31, 0–3.mp3 сняты с дискретного выхода
микроконтроллера «Школьника-2» и с тех пор не менялись. Это свидетельство
происхождения записи, не подтверждение авторства музыкальных произведений.
4.mp3 и test.mp3 исключены из свидетельства о записи с микроконтроллера.
Подробности, пробелы и условия следующего этапа: [аудит](../../docs/LICENSE_AUDIT.md).

Проверка источников и состава IPK: `make all` (host-only).

По уточнению владельца 2026-10-31, 0–4 — его записи известных мелодий;
4.mp3 — отрывок из фильма «Усатый нянь». Способ получения этого фрагмента
не установлен; права на музыку/использованную запись учитываются отдельно.
Источник test.mp3 остаётся неизвестным. Все MP3 исключены из MIT кода;
см. [область лицензии](../../docs/LICENSING.md).
